---

# 🧠 Método C.A.L.M.A.

Durante os encontros, utilizaremos o **Método C.A.L.M.A.** como estratégia
para resolução de questões.

| Etapa | Significado | Pergunta |
|---|---|---|
| **C** | Comando | O que exatamente a questão solicita? |
| **A** | Assunto | Qual conteúdo ou competência está sendo avaliado? |
| **L** | Leitura | Quais evidências do enunciado são relevantes? |
| **M** | Marcação | Quais alternativas podem ser eliminadas? |
| **A** | Avaliação | A resposta escolhida atende exatamente ao comando? |

> Antes de marcar uma alternativa, faça o C.A.L.M.A.
